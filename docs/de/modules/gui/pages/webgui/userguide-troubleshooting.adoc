[[opsi-manual-opsiwebgui-troubleshooting]]
= Troubleshooting

Dieses Kapitel beschreibt mögliche Probleme mit dem OPSI-WebGUI und bietet Tipps zur Lösung.

[[opsi-manual-opsiwebgui-troubleshooting-emptyconfigserver]]
== Leerer Config-Server-Name

Wenn die Anmeldeseite den Namen des OPSI-Configservers nicht anzeigt, haben Sie möglicherweise den Zugriff auf den Configserver oder den Dienst `opsiconfd` verloren.

Mögliche Lösungen:

* Öffnen Sie die Admin-Seite `https://<opsi-server>:4447/admin` in Ihrem Browser, melden Sie sich an und verifizieren/akzeptieren Sie das SSL-Zertifikat, falls erforderlich.

* Starten Sie den `opsiconfd`-Dienst neu, z.{nbsp}B. mit diesem Befehl:

[source,console]
----
systemctl restart opsiconfd.service
----

TIP: Für weitere Informationen über den `opsiconfd`-Dienst, seine Befehlszeile und die Admin-Seite siehe Kapitel xref:server:components/opsiconfd.adoc[*opsiconfd* Service].

== OPSI-Messagebus-Verbindung fehlgeschlagen

Wenn der OPSI-Messagebus-Status-Indikator in der oberen Leiste einen Trennungszustand anzeigt und eine Zertifikat-Warnbanner erscheint, konnte die WebSocket-Verbindung zum OPSI-Server nicht hergestellt werden.
Dies geschieht normalerweise, wenn das SSL-Zertifikat vom Browser nicht vertraut wird.

Mögliche Lösungen:

* Öffnen Sie `\https://<OPSI-Server>:4447/` direkt in Ihrem Browser und akzeptieren Sie das Zertifikat.
* Stellen Sie sicher, dass der `opsiconfd`-Dienst läuft und auf Port 4447 erreichbar ist.

Nach Behebung des Zertifikatsproblems verbindet sich der Messagebus automatisch erneut.

TIP: Für weitere Informationen über den OPSI-Messagebus siehe xref:server:components/opsiconfd.adoc#server-components-opsiconfd-admin-page-messagebus[OPSI-Messagebus].

[[opsi-manual-opsiwebgui-troubleshooting-terminal-not-available]]
== Terminal nicht verfügbar

Wenn die Seite _Terminal_ anzeigt, dass das Terminal deaktiviert ist, wurde `opsiconfd` so konfiguriert, dass die Messagebus-Terminal-Funktion deaktiviert ist.

Prüfen Sie die Konfiguration:

[source,console]
----
grep disabled-features /etc/opsi/opsiconfd.conf
----
