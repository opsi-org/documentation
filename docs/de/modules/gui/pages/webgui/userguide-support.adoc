= Support

Die Seite _Support_ in der OPSI-WebGUI bietet einen schnellen Einstieg zu Hilfe-Ressourcen und Release-Informationen.

Sie öffnen die Seite über die linke Navigation: _Support_.

.OPSI-WebGUI: Support-Seite
image::gui:webgui/opsi-webgui-support.png["OPSI-WebGUI: Support-Seite"]

Die Seite enthält drei Link-Karten:

* *Professioneller Support*: Öffnet die opsi-Support-Seite in Ihrer aktuellen Sprache.
* *Community*: Öffnet `https://forum.opsi.org`.
* *Dokumentation*: Öffnet `https://docs.opsi.org`.

Unterhalb der Karten zeigt der Bereich _Was ist neu_ aktuelle Release Notes.
Wenn keine Changelog-Einträge verfügbar sind, erscheint ein entsprechender Hinweis.
