[[opsi-manual-opsiwebgui-opsiservers]]
= Server

OPSI kennt zwei verschiedene Server-Varianten (siehe Kapitel xref:server:overview.adoc[OPSI-Server]): Configserver und Depotserver.
Der OPSI-Configserver ist die zentrale Steuerungs-Komponente jeder OPSI-Umgebung, und es gibt nur einen OPSI-Configserver.
Der Depotserver stellt Dateien der zu verteilenden Software, Betriebssysteme und Boot-Images zur Verfügung.
Es ist möglich, mehr als einen Depotserver in OPSI-Umgebungen zu betreiben.

Nach dem Anmelden und Auswahl der Serveransicht ist in der Voreinstellung der OPSI-Configserver ausgewählt; er erscheint hervorgehoben in der Tabelle.
Sie können die Auswahl verändern, wenn Sie in der linken Navigationsleiste _Server_ / _Alle Server_ öffnen.

[[opsi-manual-opsiwebgui-opsiservers-table]]
== Servertabelle

Die Servertabelle (_Server_ / _Alle Server_) listet alle bekannten Depotserver sowie den Configserver auf.
Die Zeile des OPSI-Configservers ist visuell hervorgehoben, da er der primäre Server in jeder OPSI-Umgebung ist.

Die Tabellenspalten umfassen:

* *Server-ID*: Der Hostname des Servers.
* *Beschreibung*: Optionale Beschreibung.
* *Typ*: Configserver oder Depotserver.
* *IP-Adresse*: Die konfigurierte IP-Adresse des Servers.
* *Aktionen*: Icon-Schaltfläche zum Öffnen des Detailpanels _Konfiguration_.

Tabellenfunktionen wie Filtern, Sortieren, Spaltensichtbarkeit, Seitennavigation und Auswahl funktionieren auf allen Datentabellen der OPSI-WebGUI identisch (siehe xref:gui:webgui/userguide-generalui.adoc#opsi-manual-opsiwebgui-userinterface-pagecontent[Hauptbereich]).

[[opsi-manual-opsiwebgui-opsiservers-treeselect]]
== Server im Schnellzugriff auswählen

Die Serverauswahl im Schnellzugriff ist zentral im Kapitel xref:gui:webgui/userguide-quickpanel.adoc#opsi-manual-opsiwebgui-quickpanel-servers-tab[Reiter: Server] beschrieben.

Die Server-Auswahl bestimmt den Geltungsbereich aller produktbezogenen Operationen:

* Die Seite _Produkte_ zeigt Produkte der ausgewählten Server an.
* Wenn zusätzlich Clients ausgewählt sind, beziehen sich Produktaktionen auf diese Clients und die ausgewählten Depots.

[[opsi-manual-opsiwebgui-opsiservers-attributes-parameter]]
== Attribute und Parameter bearbeiten

Um die Server-Attribute und -Parameter zu bearbeiten, öffnen Sie entweder den Eintrag _Server_ / _Konfiguration_ in der linken Navigationsleiste oder Sie klicken neben einem Server in der Tabelle auf das Zahnradsymbol (*Konfiguration*).

TIP: Der Klick auf das Zahnradsymbol und das Einblenden der Konfiguration direkt neben der Serverliste hat den Vorteil, dass Sie schnell zwischen den Einstellungen für die verschiedenen Server wechseln können. Wenn die Tabelle im Single-Select-Modus ist, genügt ein Klick auf den Servereintrag selbst, um ihn auszuwählen und gleichzeitig seine Konfiguration zu öffnen.

Das Konfigurationsdetailpanel eines Servers bietet zwei Reiter:

* *Parameter*: Zeigt alle OPSI-Host-Parameter des ausgewählten Servers an und erlaubt deren Bearbeitung.
* *Attribute*: Server-Attribute bearbeiten, z.{nbsp}B. Beschreibung, Notizen und Netzwerkkonfiguration.

Um die Standard-Parameter zu ändern, wählen Sie aus der linken Leiste _Server_ / _Konfiguration_ und wechseln zum Reiter _Parameter (Defaults)_.

NOTE: Der Selektor auf _Server / Konfiguration_ ist lokal für diese Seite. Änderungen dort verändern keine globalen Auswahlen und keine Ziele von Aktionen auf anderen Seiten.
