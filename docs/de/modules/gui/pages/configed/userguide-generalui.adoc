= Benutzeroberfläche

Nach der erfolgreichen Anmeldung sehen Sie das `opsi-configed`-Hauptfenster. Auf der linken Seite finden Sie eine Gruppe von Icons, über die Sie die verschiedenen Hauptdarstellungen auswählen können. Standardmäßig ist die Client-Konfiguration ausgewählt. Folgende Darstellungen existieren:

* xref:gui:configed/userguide-clients.adoc[Client-Konfiguration]
* xref:gui:configed/userguide-depots.adoc[Depot-Konfiguration]
* xref:gui:configed/userguide-server.adoc[Server-Konfiguration]
* Dashboard
* xref:gui:configed/userguide-validation-opsi-modules.adoc[Validierungsstatus der OPSI-Module]
* Health Check
* xref:opsi-modules:licensemanagement.adoc[Lizenzmanagement]

.*opsi-configed*: Icons für die Hauptdarstellungen
image::gui:opsi-configed-toolbar-left.png["*opsi-configed*: Icons für die Hauptdarstellungen", pdfwidth=80%]

In der oberen Leiste steht in der Mitte der Titel der aktuell ausgewählten Ansicht. Auf der linken Seite sind ein Icon für einen kompletten Reload aller Daten und ein Icon für zum Abspeichern. Auf der rechten Seite befinden sich Ansichts-spezifische Icons, die je nach ausgewählter Ansicht unterschiedliche Funktionen haben. In der Client-Konfiguration gibt es ein Icon für das Erstellen eines neuen Clients und eines für eine freie Client-Suche.

.*opsi-configed*: Hier ist die Client-Konfiguration ausgewählt
image::gui:opsi-configed-toolbar-top.png["*opsi-configed*: Hier ist die Client-Konfiguration ausgewählt", pdfwidth=80%]

TIP: Aus fast allen Bereichen können Sie Daten in die Zwischenablage kopieren und die Daten in andere Anwendungen einfügen. Außerdem unterstützen die meisten `opsi-configed`-Tabellen Drag{nbsp}&{nbsp}Drop. So können Sie Tabellendaten komfortabel in eine Tabellenkalkulation übertragen.

== Helles und dunkles Theme

Ab OPSI 4.3 unterstützt `opsi-configed` einen Dark Mode. Um diesen zu aktivieren, öffnen Sie aus dem Menü _Datei_ den Eintrag _Ansicht_ / _Dunkel_.

.*opsi-configed*: Dark Mode
image::gui:opsi-configed-dark-mode.png["*opsi-configed*: Dark Mode", width=800, pdfwidth=80%]

Um zurück zur hellen Ansicht zu wechseln, wählen Sie im Menü _Datei_ den Eintrag _Ansicht_ / _Hell_.

NOTE: `opsi-configed` speichert auf dem lokalen Rechner (auf dem Sie das Programm gestartet haben) einige Einstellungen, darunter das gewählte Theme, die zuletzt ausgewählten Clients/Gruppen und Depots. Beim nächsten Start finden Sie sich also in der gleichen Ansicht wieder.
