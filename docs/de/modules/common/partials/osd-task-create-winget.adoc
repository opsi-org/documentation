=== Opsi winget Paket erzeugen

Der folgenden Abschnitt beschreibt, wie Sie ein winget basiertes opsi-Produkt erstellen. +
`winget` ist ein Windows Kommandozeilen Befehl mit dem Sie Software direkt aus dem Internet auf den Rechner installieren können. +
In der Regel muß winget zunächst auf dem Rechner installiert werden. Dazu stellen wir das opsi Paket `ms-winget-cli` zur Verfügung. +
Um ein winget basiertes Paket zu erstellen klicken Sie auf der Startseite (<<osd_page_start>>) auf die Schaltfläche _Erzeuge ein opsi winget Paket_. Danach bekommen Sie die folgenden Hinweis zu sehen:

.Der *opsi-setup-detector* winget Hinweis.
image::osd_installer_info_winget_de.png["Der *opsi-setup-detector* winget Hinweis.", pdfwidth=80%, width=800]

Nach dem Sie den Hinweis bestätigt haben, bekommen Sie die folgende Maske zu sehen:

.Der *opsi-setup-detector* winget Eingabe Maske.
image::osd_page_winget_de.png["Der *opsi-setup-detector* winget Eingabe Maske.", pdfwidth=80%, width=800]

Hier geben Sie die `wingetId` und die `wingetSource` ein. +
In den Feldern 'Kommando zur Installation' und 'Kommando zur Deinstallation' können Sie sehen mit welchem Kommando die Software dann (De-)Installiert wird. +
Über den Button `Nächster Schritt` kommen Sie dann zur `Produktkonfiguration 1` die Sie wie bei den anderen Tasks verwenden. +
 +
Typische `wingetSource` sind `winget` und `msstore`. +
Werkzeuge zur Ermittlung von `wingetId` und `wingetSource` finden Sie hier: +
`Unigetui` ist ein lokal zu Installierendes Werkzeug mit dem Sie nach im Netz verfügbaren Paketen aus unterschiedlichen Quellen suchen können. Bei gefundenen Paketen können Sie über das Kontextmenü / Paketdetails umfangreiche Informationen über das Paket erhalten. (Runterscrollen nicht vergessen). 
Evtl. finden Sie hier auch einen Link wo der ursprüngliche Installer heruntergeladen werden kann. + 
Siehe: link:https://www.marticliment.com/unigetui/[unigetui] +
`winget.run` ist eine webseite mit der die `wingetId` von Paketen aus der Quelle `winget` ermittelt werden kann (also keien Pakete aus dem MS-Store). +
Siehe: link:https://winget.run/[winget.run] +
Weiter Seiten mit Detailinformationen zum Befehl `winget` finden Sie bei link:https://learn.microsoft.com/de-de/windows/package-manager/winget/[learn.microsoft] +
und bei link:https://de.wikipedia.org/wiki/Windows_Package_Manager[wikipedia]
