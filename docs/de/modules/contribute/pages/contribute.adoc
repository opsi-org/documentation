[[opsi-mitmachen]]
= Bei OPSI mitmachen

Es gibt mehrere Möglichkeiten, das opsi-Projekt zu unterstützen. Egal, ob Sie Patches für die Software selbst oder unser Handbuch einreichen möchten -- Sie benötigen einen GitHub Account (https://github.com), um mitzumachen. Alle Beiträge müssen über Pull Requests eingereicht werden.
