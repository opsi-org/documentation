= Déploiement de produits sur les clients

Nous allons maintenant déployer le produit `hwaudit` sur tous les clients. Ce produit effectue un inventaire matériel en recueillant des informations sur tous les périphériques. Pour cela, nous utiliserons l'xref:opsi-docs-en:gui:configed.adoc[interface d'administration *opsi-configed* (en anglais)]. Vous pouvez également déployer le produit avec l'xref:opsi-docs-en:gui:webgui.adoc[OPSI WebGUI (en anglais)].

TIP: Vous trouverez une description complète des produits, de leur déploiement sur les clients et d'autres sujets dans les xref:opsi-docs-en:clients:opsi-clients.adoc[manuels des clients (en anglais)].

Dans l'interface, commencez par sélectionner un ou plusieurs clients. Ouvrez ensuite l'onglet _Localboot products_ (produits Localboot). Sélectionnez le produit `hwaudit` dans la liste et cliquez dans la colonne _Requested action_ (action demandée). Dans le menu déroulant qui apparaît, sélectionnez l'option _setup_. Pour exécuter immédiatement l'action, ouvrez le menu contextuel par un clic droit et choisissez l'option _Save and execute_ (enregistrer et exécuter).

.Déploiement du produit *hwaudit* sur un client.
image::opsi-docs-en:common:opsi-configed-hwaudit-setup.png["Déploiement du produit *hwaudit* sur un client.", width=800, pdfwidth=80%]

Le produit est maintenant déployé sur les clients sélectionnés. Lorsque l'état dans la colonne _Requested action_ passe de _setup_ à _installed_, vous pouvez consulter les résultats de l'inventaire matériel dans l'onglet _Hardware information_ (informations matérielles).

Vous pouvez à présent installer d'autres produits sur le serveur, puis les déployer sur les clients.

NOTE: Il n'est pas nécessaire de déployer les produits immédiatement. Vous pouvez attendre le prochain démarrage. Les clients exécutent automatiquement les actions en attente avant la connexion de l'utilisateur.
