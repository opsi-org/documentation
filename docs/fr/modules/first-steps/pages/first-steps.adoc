[[quick-start-intro]]
= Démarrage rapide

Ce chapitre propose une introduction rapide à opsi, en commençant par l'installation d'un serveur OPSI avec Docker ou une machine virtuelle préconfigurée. Les chapitres suivants vous guideront dans la création de nouveaux clients OPSI, l'intégration d'ordinateurs existants en tant que clients OPSI et la distribution de produits à ces clients.

1. Installez un serveur OPSI, soit avec xref:server/server-installation-docker.adoc[Docker], soit à l'aide de la xref:server/server-installation-vm.adoc[machine virtuelle] prête à l'emploi.
2. Téléchargez l'interface utilisateur xref:gui/configed.adoc[*opsi-configed*].
3. Mettez des produits à disposition sur votre serveur en installant des xref:products/products.adoc[produits OPSI].
4. Enregistrez un ou plusieurs clients auprès du serveur (voir le chapitre xref:clients/client-installation.adoc[Ajout de clients]).
5. xref:rollout/rollout.adoc[Déployez] les produits précédemment installés sur vos clients.

NOTE: Pour une description complète de l'installation du serveur, couvrant toutes les variantes, consultez le chapitre xref:opsi-docs-en:server:overview.adoc[Serveur OPSI (en anglais)]. Des manuels détaillés consacrés aux clients sont disponibles dans le chapitre xref:opsi-docs-en:clients:opsi-clients.adoc[Clients OPSI (en anglais)], avec des guides spécifiques pour les clients xref:opsi-docs-en:clients:windows-client/windows-client-manual.adoc[Windows (en anglais)], xref:opsi-docs-en:clients:linux-client/linux-client-manual.adoc[Linux (en anglais)] et xref:opsi-docs-en:clients:macos-client/mac-client-manual.adoc[macOS (en anglais)].

TIP: Vous souhaitez découvrir les extensions OPSI ? Avec la xref:opsi-docs-en:opsi-modules:modules.adoc#opsi-basic-license[licence OPSI Basic (en anglais)], vous pouvez tester et utiliser gratuitement (presque) toutes les extensions OPSI sur un maximum de 30 clients. Pour en savoir plus, consultez le chapitre xref:opsi-docs-en:opsi-modules:modules.adoc[Extensions OPSI (en anglais)].
