[[quick-start-osinstall-create-client]]
= Ajout de clients


Ce chapitre explique comment intégrer des clients Windows dans l'environnement OPSI. Pour des instructions détaillées, consultez le chapitre xref:opsi-docs-en:clients:opsi-clients.adoc[Clients OPSI (en anglais)].

TIP: OPSI permet également de gérer des clients Linux et macOS. Pour en savoir plus, consultez les chapitres xref:opsi-docs-en:clients:linux-client/linux-client-manual.adoc[Clients Linux (en anglais)] et xref:opsi-docs-en:clients:macos-client/mac-client-manual.adoc[Clients macOS (en anglais)].

[[firststeps-software-deployment-client-integration]]
== Intégration de clients existants

Pour ajouter à opsi des clients existants sur lesquels un système d'exploitation est déjà installé, vous devez installer l'agent client sur chaque ordinateur concerné. Une fois l'installation terminée, le client apparaît également dans la liste des clients de l'interface d'administration `opsi-configed`, même si vous ne l'y avez pas ajouté manuellement :

xref:opsi-docs-en:clients:windows-client/windows-client-agent.adoc[Instructions pour Windows (en anglais)]
