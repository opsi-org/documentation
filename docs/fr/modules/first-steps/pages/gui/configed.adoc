= Interface utilisateur OPSI

Deux interfaces graphiques sont actuellement disponibles pour administrer le serveur OPSI, les clients et les tâches associées :

* L'application Java xref:opsi-docs-en:gui:configed.adoc[*opsi-configed* (en anglais)]
* L'interface xref:opsi-docs-en:gui:webgui.adoc[OPSI-WebGUI (en anglais)] pour les navigateurs web

Ce chapitre est consacré à l'interface `opsi-configed`.

== *opsi-configed* : téléchargement et lancement

Une version portable de l'application est disponible à l'adresse link:https://tools.43.opsi.org/{release}/[]. Téléchargez la version d'`opsi-configed` adaptée à votre système d'exploitation : `opsi-configed-windows.exe` pour Windows, `opsi-configed-linux.run` pour Linux et `opsi-configed-macos` pour macOS.

NOTE: Sous Linux et macOS, vous devez rendre le fichier téléchargé exécutable. Utilisez la commande `chmod` :

[source,console]
----
chmod +x opsi-configed-linux.run
chmod +x opsi-configed-macos
----

Au lancement de l'application, une fenêtre de connexion apparaît. Saisissez le nom d'hôte complet (FQDN) du serveur OPSI ou son adresse IP, ainsi que le nom d'utilisateur et le mot de passe :

.*opsi-configed* : connexion
image::opsi-docs-en:first-steps:opsi-configed-login.png["*opsi-configed* : connexion", pdfwidth=80%]

Si la connexion réussit, la fenêtre principale s'affiche :

.*opsi-configed* : fenêtre principale
image::opsi-docs-en:first-steps:opsi-configed-clients.png["*opsi-configed* : fenêtre principale", width=800, pdfwidth=80%]

La capture d'écran présente déjà des clients et des produits OPSI. Lors de la configuration initiale, ces éléments peuvent toutefois ne pas encore être visibles dans votre environnement. Pour apprendre à mettre des produits (paquets OPSI) à disposition sur le serveur, passez au chapitre suivant.
