= Ajout de produits (serveur)

OPSI propose des produits prêts à l'emploi pour la distribution de logiciels, que vous devez d'abord installer sur le serveur. Parmi ces produits figure l'xref:opsi-docs-en:clients:windows-client/windows-client-agent.adoc[agent client pour Windows (en anglais)]. OPSI utilise un agent dédié sur les ordinateurs clients pour réaliser les installations et les mises à jour de manière fluide et automatique, sans intervention de l'utilisateur.

== Installation d'*opsi-client-agent*, d'*opsi-script* et de *hwaudit*

Pour installer les produits `opsi-client-agent`, `opsi-script` et `hwaudit` (pour l'inventaire matériel) sur le serveur OPSI, vous devez ouvrir un terminal sur le serveur, soit localement, soit via SSH.

TIP: Vous pouvez également accéder à un terminal directement depuis l'interface `opsi-configed`. Il suffit de sélectionner _Terminal_ dans le menu _Server console_ (console du serveur) :

.*opsi-configed* : ouverture d'un terminal
image::opsi-docs-en:first-steps:opsi-configed-terminal.png["*opsi-configed* : ouverture d'un terminal", width=800, pdfwidth=80%]

Pour installer les paquets `opsi-client-agent`, `opsi-script` et `hwaudit`, saisissez la commande suivante dans le terminal :

[source,console]
----
opsi-package-updater -v install opsi-client-agent opsi-script hwaudit
----

NOTE: Pour configurer `opsi-package-updater` ou installer manuellement des paquets, consultez le chapitre xref:opsi-docs-en:clients:windows-client/minimal-products.adoc[Ajout de produits (serveur) (en anglais)]. Si vous souhaitez créer vos propres paquets OPSI, vous trouverez des instructions détaillées dans le chapitre xref:opsi-docs-en:clients:windows-client/softwareintegration.adoc[Intégration de logiciels personnalisés (en anglais)].

L'étape suivante consiste à enregistrer un ou plusieurs clients auprès du serveur.
