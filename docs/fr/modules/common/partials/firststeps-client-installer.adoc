== Utilisation du programme d’installation sur le client

Cette méthode convient particulièrement à l’intégration de postes individuels comme clients dans un environnement OPSI. Procédez comme suit :

. Connectez-vous au client.
. Téléchargez le programme d’installation depuis votre serveur de configuration OPSI. Il est disponible à l’adresse `\https://<fqdn_or_ip_of_the_config_server>:4447/public/opsi-client-agent/` ; le programme Windows se nomme `opsi-client-agent-installer.exe`.
. Exécutez le programme d’installation ; il se décompresse dans un répertoire local temporaire et lance le programme `oca-installation-helper` qu’il contient. Dans la boîte de dialogue, saisissez l’identifiant du client, l’URL du service OPSI, le nom d’utilisateur et le mot de passe. Les champs sont préremplis dans la mesure du possible ; adaptez les valeurs à votre environnement si nécessaire :
   * L’identifiant du client correspond généralement à son FQDN.
   * L’URL du service OPSI doit respecter le format `\https://<fqdn_or_ip_of_config_server>:4447`.
   * Lors de la première installation du client, le nom d’utilisateur et le mot de passe doivent correspondre à un compte membre du groupe `opsiadmin` (voir le chapitre xref:opsi-docs-en:server:components/authorization.adoc[Autorisations (en anglais)]). Lors d’une réinstallation, vous pouvez également utiliser l’identifiant du client et la clé d’hôte.
. Le programme d’installation contacte le serveur via le service web OPSI pour y enregistrer le client. Il appelle ensuite le programme `opsi-script` inclus afin d’exécuter le fichier `setup.opsiscript` de l’agent client.
