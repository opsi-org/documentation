[[server-installation-base-vm]]
= Machine virtuelle préconfigurée

Nous avons préparé une machine virtuelle disponible en link:https://tools.43.opsi.org/{release}/opsi43-vm.zip[téléchargement]. Vous pouvez l’utiliser avec link:https://www.virtualbox.org/[VirtualBox], link:https://www.vmware.com/products/desktop-hypervisor[VMware Desktop Hypervisor], link:https://www.vmware.com/products/cloud-infrastructure/vsphere[VMware vSphere] ou link:https://www.proxmox.com/de/[Proxmox]. Nous recommandons d’utiliser cette machine virtuelle principalement pour tester OPSI. Pour une utilisation en production, choisissez l’une des méthodes d’installation décrites au chapitre xref:server:installation/installation.adoc[Installation et configuration].

[[server-installation-base-vm-start]]
== Téléchargement et importation

Après avoir téléchargé la machine virtuelle, décompressez l’archive. Le dossier décompressé contient trois fichiers : `opsi[...].vmdk`, `opsi[...].mf` et `opsi[...].ovf`.

Pour importer la machine virtuelle, procédez comme suit :

*VMware Workstation Player*

. Sélectionnez l’entrée de menu _Open a Virtual Machine_ et, dans la boîte de dialogue de sélection de fichiers, accédez au répertoire contenant les fichiers de l’archive zip que vous venez de décompresser.

. Sélectionnez l’option de menu _Open a Virtual Machine_ et, dans la boîte de dialogue de sélection de fichiers, accédez au répertoire contenant les fichiers de l’archive zip récemment décompressée.
. Sélectionnez le fichier portant l’extension `.ovf`. Si nécessaire, choisissez le type de fichier `Virtual Machines (*.vmx, *.ovf, *.ova)` en bas de la boîte de dialogue.
. Après avoir cliqué sur _Open_, vous pouvez attribuer un nom à la machine et choisir son emplacement de stockage.
. Cliquez sur _Import_ pour terminer l’opération.
. Vous pouvez maintenant démarrer la nouvelle VM en sélectionnant _Power On_.

.VMware Workstation Player : importation de la machine virtuelle
image::opsi-docs-en:server:opsiconfd/opsi-vm-vmware-import.png["VMware Workstation Player : importation de la machine virtuelle", pdfwidth=80%]

*Serveur ESXi*

. Démarrez le client vSphere.
. Créez une nouvelle machine via _File_ / _Deploy OVF Template_, puis accédez au fichier `.ovf`.
. Cliquez sur _Open_, puis sur _Next_.
. Saisissez un nom pour la machine ou acceptez la valeur par défaut.
. Cliquez sur _Next_ pour vérifier tous les paramètres. Cliquez sur _Finish_ pour lancer l’importation.

*VirtualBox*

. Dans le menu, choisissez _File_ / _Import Appliance_.
. Dans la boîte de dialogue de sélection de fichiers, accédez au fichier `.ovf` et cliquez sur _Open_.
. Après avoir cliqué sur _Next_, vous pouvez adapter les paramètres dans la boîte de dialogue suivante, par exemple changer le nom ou la taille de la mémoire vive.
. Cliquez sur _Import_ pour terminer l’opération.

.VirtualBox : importation de la machine virtuelle
image::opsi-docs-en:server:opsiconfd/opsi-vm-import-en.png["VirtualBox : importation de la machine virtuelle", width=800, pdfwidth=80%]

*Proxmox*

 . Connectez-vous à votre hôte Proxmox via SSH et exécutez les commandes suivantes :
 [source,bash]
 ----
 wget https://tools.43.opsi.org/{release}/opsi43-vm.zip
 unzip opsi43-vm.zip
 qm importovf VMID /mnt/pve/storage01_vmimages/opsi43-vm-VERSION.ovf STORAGEPOOL
 ----

Remplacez VMID par un identifiant libre, STORAGEPOOL par le pool que vous avez configuré et VERSION par la version d’opsi-vm que vous venez de télécharger.
Si vous le souhaitez, une fois l’importation terminée, vous pouvez remplacer le nom `opsi-vm` par un autre nom dans les options de la VM.

[[server-installation-base-vm-1stboot]]
== Premier démarrage : le script *firstboot*

Le script `firstboot`, qui s’exécute automatiquement lors du premier démarrage de l’appliance, vous aide à configurer le réseau. Le fichier journal de `firstboot` se trouve dans `/var/tmp/firstboot.log`.

WARNING: Le script `firstboot` ne doit pas être utilisé pour renommer un serveur OPSI déjà configuré !

.Le script *firstboot* vous aide à configurer le réseau.
image::opsi-docs-en:server:1st-startup-mask.png["Le script *firstboot* vous aide à configurer le réseau.", pdfwidth=80%]

Le script vous demande les informations suivantes :

Langue:: Sélectionnez la langue souhaitée pour le système : `english`, `german` ou `french`.

Nom du serveur:: Indiquez le nom de ce serveur OPSI (sans le domaine), par exemple `opsiserver` ou `opsidepot`.

Domaine:: Saisissez le domaine DNS (et non le domaine Windows ; il doit contenir un point), par exemple `mycompany.internal`.

Adresse IP:: Adresse IP du serveur, par exemple `192.168.1.50`.

Passerelle:: Adresse IP de la passerelle réseau, par exemple `192.168.1.1`.

DNS:: Adresse IP du serveur DNS, par exemple `192.168.1.1`.

Masque de réseau:: Masque de réseau du serveur, par exemple `255.255.255.0`.

Backend DHCP:: Indiquez si vous souhaitez utiliser le backend DHCP d’OPSI. Cela est utile si vous ne disposez pas déjà d’un serveur DHCP.

Proxy:: Adresse et port du serveur proxy, si nécessaire, par exemple `\http://myuser:mypass@192.168.1.5:8080`.

Mot de passe pour root:: Définissez un mot de passe pour le compte administrateur local. Saisissez-le deux fois pour le confirmer et éviter les erreurs de frappe.

Mot de passe pour adminuser:: Définissez un mot de passe pour l’administrateur OPSI local. Saisissez également ce mot de passe deux fois.

Lorsque tous les champs sont renseignés et valides, un bouton apparaît en bas de la fenêtre.
Cliquez sur ce bouton pour configurer la VM OPSI. Après un redémarrage, l’appliance virtuelle est prête à l’emploi.

[[server-installation-base-vm-second-start]]
== Deuxième démarrage : connexion et mise à jour

Après le redémarrage, connectez-vous à l’environnement graphique avec le nom d’utilisateur `adminuser` et le mot de passe défini pendant l’installation. La machine virtuelle comprend trois environnements de bureau légers, que vous pouvez sélectionner dans le menu _Session_ en haut de l’écran.

Après la connexion, le navigateur Firefox démarre et ouvre une page contenant des liens supplémentaires vers le manuel, notre forum d’entraide communautaire, le wiki OPSI et l’assistance professionnelle d’uib.

.L’environnement de bureau graphique du serveur OPSI
image::opsi-docs-en:server:opsiconfd/opsi-vm-welcome-en.png["L’environnement de travail graphique du serveur OPSI", width=800, pdfwidth=80%]

NOTE: Si un message indique qu’aucune connexion réseau n’est disponible, cela peut être dû à la configuration particulière de l’appliance virtuelle. Avant de rechercher la cause du problème, il est recommandé de redémarrer le serveur. Vous pouvez cliquer sur le bouton d’arrêt dans le menu de démarrage ou saisir la commande `reboot` dans une fenêtre de terminal.

Pour mettre à jour les paquets du système Linux sous-jacent vers leurs dernières versions, utilisez l’icône _Update OS_ sur le bureau. Double-cliquez sur cette icône et, lorsqu’un mot de passe vous est demandé, saisissez celui de l’utilisateur `adminuser`.

La machine virtuelle étant basée sur Ubuntu, vous pouvez également mettre à jour les paquets avec `apt`. Ouvrez un terminal et exécutez les commandes suivantes :

[source,console]
----
sudo apt update
sudo apt --yes --auto-remove upgrade
----
