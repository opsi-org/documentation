== Docker Compose

Le fichier de configuration `docker-compose.yml` définit les réseaux, les volumes et les quatre services suivants (section `services`) :

* `mysql` : met en place le serveur de base de données MariaDB.
* `redis` : installe la base de données en mémoire Redis avec le module RedisTimeSeries.
* `grafana` : déploie une version actuelle de Grafana.
* `opsi-server` : installe les dernières versions des paquets `opsiconfd`, `opsipxeconfd`, `opsi-tftpd-hpa` et `opsi-utils`.

Au début du fichier, plusieurs propriétés X (champs d’extension), telles que `x-restart-policy`, `x-common-variables`, etc., sont définies. Ces ancres YAML permettent de partager les paramètres entre les services.

Vous y trouverez également plusieurs variables d’environnement pour les conteneurs. Vous pouvez les modifier directement dans le fichier `docker-compose.yml` ou les définir dans le fichier fourni `opsi-server.env`, qui est lu au démarrage (comme défini dans le fichier `docker-compose-env.yml`). Le fichier fourni se trouve dans le dépôt GitHub link:https://github.com/opsi-org/opsi-docker[opsi-docker,window=_blank]. Le fichier `.env` centralise ainsi la configuration et vous évite de rechercher les variables dans `docker-compose.yml`. Vous pouvez ensuite démarrer la pile avec cette commande :

[source,console]
----
docker compose -f docker-compose-env.yml up
----

NOTE: Pour renforcer la sécurité, il est essentiel de modifier tous les mots de passe dans le fichier `docker-compose.yml` : `MYSQL_ROOT_PASSWORD`, `MYSQL_PASSWORD`, `REDIS_PASSWORD`, `GF_SECURITY_ADMIN_PASSWORD` et `OPSI_ADMIN_PASSWORD`.

Par défaut, aucun mot de passe n’est défini pour l’utilisateur `root`. Vous pouvez en attribuer un avec `OPSI_ROOT_PASSWORD` :

[source,toml]
----
OPSI_ROOT_PASSWORD: <password>
----

TIP: Si vous n’avez pas besoin du démarrage réseau TFTP (et donc de `opsipxeconfd` et `opsi-tftp-hpa`), vous pouvez le désactiver en définissant la variable `OPSI_TFTPBOOT` sur `"false"`.

Les deux sections suivantes expliquent comment adapter le fichier de configuration `docker-compose.yml` pour configurer un serveur de configuration ou un serveur de dépôt.
