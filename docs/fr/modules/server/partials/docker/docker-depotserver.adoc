[[server-installation-docker-compose-depot]]
=== Serveur de dépôt OPSI

Vous pouvez utiliser notre image Docker pour mettre en place un serveur de dépôt OPSI. Cela suppose qu’un serveur de configuration OPSI existe déjà et qu’il soit accessible sur le réseau. Vérifiez notamment que l’hôte Docker peut joindre le serveur de configuration sur le port 4447 via HTTPS (voir la section xref:opsi-docs-en:server:components/network.adoc#server-components-network-ports[Protocoles et ports utilisés (en anglais)]). Vous pouvez utiliser `curl` en ligne de commande à cette fin (Windows : invite de commandes ; Linux/macOS : terminal) :

[source,console]
----
curl --insecure https://<fqdn>:4447/public
----

Remplacez `<fqdn>` par le FQDN ou l’adresse IP du serveur de configuration OPSI ; le répertoire `public` est généralement accessible sans authentification sur ce serveur. Vous recevrez un fichier XML en réponse.

Créez également un nouveau dépôt sur le serveur de configuration. Le plus simple est d’utiliser l’onglet _Depots_ de la xref:opsi-docs-en:server:components/opsiconfd.adoc#server-components-opsiconfd-admin-page[page d’administration (en anglais)]. Saisissez le FQDN de l’hôte Docker et, si vous le souhaitez, une description, puis cliquez sur _Create depot_. Le nouveau dépôt devrait apparaître immédiatement dans la liste ; vous aurez besoin de sa clé d’hôte pour configurer le serveur de dépôt.

.Page d’administration : création d’un nouveau dépôt
image::opsi-docs-en:server:create-depot-admin.png["Page d’administration : création d’un nouveau dépôt", pdfwidth=80%]

Sur l’hôte du serveur de dépôt, commencez avec les mêmes fichiers que pour le serveur de configuration OPSI.
Modifiez le fichier `docker-compose.yml` dans l’éditeur de texte de votre choix. Un serveur de dépôt n’a pas besoin des deux services `mysql` et `grafana` ; vous pouvez donc les mettre en commentaire ou les supprimer. Si vous choisissez d’exclure ces services, veillez également à supprimer `mysql` de l’attribut `depends_on` dans la section `opsi-server`.

Pour configurer le serveur en tant que serveur de dépôt, définissez la variable `OPSI_HOST_ROLE` sur `depotserver` :

[source,toml]
----
OPSI_HOST_ROLE: depotserver
----

La mise en place d’un serveur de dépôt nécessite également deux variables supplémentaires : `OPSI_SERVICE_ADDRESS` (l’URL du service du serveur de configuration OPSI) et `OPSI_HOST_KEY` (la clé d’hôte du dépôt). Une fois ces variables définies, démarrez tous les services avec `./opsi-server.sh start` (Linux, macOS) ou `.\opsi-server.ps1 start` (Windows).

NOTE: Vous trouverez la clé d’hôte du serveur de dépôt OPSI dans l’interface d’administration du serveur de configuration OPSI, dans l’onglet _Depots_. Cliquez sur les points pour afficher la clé.
