= OPSI en tant que conteneur Docker

Depuis 2022, une link:https://github.com/opsi-org/opsi-docker[image Docker,window=_blank] est disponible pour mettre en place un serveur de configuration OPSI ou un serveur de dépôt OPSI. Cette solution utilise Docker Compose, un outil d’orchestration permettant de définir, d’interconnecter et d’exécuter plusieurs conteneurs sur un hôte Docker. Elle nécessite Docker Compose version 1.17.0 ou ultérieure et Docker Engine version 17.09.0 ou ultérieure.

NOTE: Dans cette configuration, la communication avec le dépôt OPSI utilise exclusivement le protocole WebDAV ; cette variante ne prend pas en charge Samba.

== Installation de Docker

Installez Docker ou Docker Desktop sur Linux, Windows ou macOS :

* link:https://docs.docker.com/desktop/install/windows-install/[Installer Docker Desktop sur Windows,window=_blank]
* link:https://docs.docker.com/desktop/install/mac-install/[Installer Docker Desktop sur macOS,window=_blank]
* link:https://docs.docker.com/desktop/install/linux-install/[Installer Docker Desktop sur Linux,window=_blank]

TIP: Sous Linux, vous pouvez également utiliser directement Docker Engine. Il suffit d’installer les paquets correspondants pour votre distribution Linux.

Pour vérifier que l’installation a réussi, exécutez la commande suivante dans le terminal :

[source,console]
----
docker run --rm hello-world
----

NOTE: Par défaut, la commande `docker` nécessite les privilèges root ; l’utilisation de nos scripts auxiliaires nécessite donc également ces privilèges. Vous pouvez préfixer les commandes présentées dans ce chapitre par `sudo` ou ajouter un compte utilisateur au groupe `docker`. Pour plus d’informations, consultez le chapitre link:https://docs.docker.com/engine/install/linux-postinstall/[Linux post-installation steps for Docker Engine] du manuel Docker.

Vous devriez obtenir une sortie semblable à celle-ci :

[source,console]
----
Hello from Docker!
This message shows that your installation appears to be working correctly.
[...]
----
