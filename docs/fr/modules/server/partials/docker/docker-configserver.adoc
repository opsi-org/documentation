=== Serveur de configuration OPSI

Après avoir adapté le nom d’hôte et le domaine dans la section `opsi-server` à votre configuration réseau, définissez la variable `OPSI_HOST_ROLE` sur `configserver` :

[source,toml]
----
OPSI_HOST_ROLE: configserver
----

Sous Linux et macOS, vous pouvez démarrer tous les services avec la commande `./opsi-server.sh start`. Sous Windows, utilisez `.\opsi-server.ps1 start` (consultez la section <<server-installation-docker-scripts>> pour plus de détails). Pour vérifier l’état des conteneurs, utilisez `./opsi-server.sh status` (Linux, macOS) ou `.\opsi-server.ps1 status`. Pour consulter les fichiers journaux, utilisez `./opsi-server.sh logs` ou `.\opsi-server.ps1 logs`.
