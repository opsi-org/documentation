[[server-installation-docker-quick]]
== Démarrage rapide

Un script auxiliaire facilite la mise en place et la gestion d’un environnement Docker OPSI.

NOTE: Les spécialistes de Docker peuvent se passer du script auxiliaire et consulter directement toutes les informations dans notre dépôt GitHub link:https://github.com/opsi-org/opsi-docker[opsi-docker,window=_blank].

=== Windows

Sous Windows, procédez comme suit :

1. Créez un dossier `opsi-server`.
2. Téléchargez le script link:https://raw.githubusercontent.com/opsi-org/opsi-docker/main/opsi-server/opsi-server.ps1[opsi-server.ps1,window=_blank] et enregistrez-le dans le dossier `opsi-server`.
3. Ouvrez PowerShell avec les privilèges d’administrateur.
4. Exécutez la commande suivante dans la fenêtre du terminal : `PowerShell.exe -ExecutionPolicy Bypass`
5. Accédez au dossier `opsi-server` à l’aide de la commande `cd`.
6. Exécutez le script en saisissant `.\opsi-server.ps1 start`.

=== Linux et macOS

Sous Linux et macOS, procédez comme suit :

Pour la mise en place sous Linux, procédez comme suit :

1. Créez un dossier `opsi-server`.
2. Téléchargez le script link:https://raw.githubusercontent.com/opsi-org/opsi-docker/main/opsi-server/opsi-server.sh[opsi-server.sh,window=_blank] et placez-le dans le dossier `opsi-server`.
3. Ouvrez un terminal avec les privilèges `root`.
4. Accédez au dossier `opsi-server` à l’aide de `cd`.
5. Rendez le script exécutable : `chmod +x opsi-server.sh`
6. Exécutez le script avec la commande `./opsi-server.sh start`.

Cette procédure télécharge automatiquement les images Docker nécessaires et démarre les conteneurs.

* Utilisez `.\opsi-server.ps1 status` ou `./opsi-server.sh status` pour vérifier l’état des conteneurs.
* Consultez les journaux des conteneurs avec `.\opsi-server.ps1 logs` ou `./opsi-server.sh logs`.
* Mettez les conteneurs à jour vers les dernières versions avec `.\opsi-server.ps1 upgrade` ou `./opsi-server.sh upgrade`.

IMPORTANT: Un fichier `docker-compose.yml` se trouve désormais dans le dossier `opsi-server`. Ouvrez ce fichier dans un éditeur de texte et recherchez la variable d’environnement `OPSI_ADMIN_PASSWORD`. Vous aurez besoin du mot de passe indiqué pour vous connecter au serveur OPSI en tant qu’utilisateur `adminuser` lors des étapes suivantes.

NOTE: Pour des raisons de sécurité, nous recommandons vivement de modifier ce mot de passe.

Si vous modifiez le fichier `docker-compose.yml`, redémarrez les conteneurs pour appliquer les changements. Pour cela, saisissez `.\opsi-server.ps1 recreate` ou `./opsi-server.sh recreate`.
