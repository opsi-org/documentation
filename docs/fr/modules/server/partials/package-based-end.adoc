TIP: À la place du paquet `opsi-server-full`, vous pouvez installer `opsi-server` ou `opsi-server-expert`. Ces paquets se distinguent par leurs dépendances et conviennent aux situations où vous préférez exécuter MySQL, Redis ou Grafana sur des serveurs distincts. Bien que `opsi-server` et `opsi-server-expert` offrent davantage de souplesse, ils s’adressent surtout aux administrateurs Linux expérimentés.

NOTE: Assurez-vous que la configuration de votre pare-feu et de SELinux autorise les connexions sur les ports 69/UDP (TFTP), 4447/TCP et 4441/TCP (opsi). Vous trouverez davantage d’informations sur SELinux dans xref:opsi-docs-en:security:selinux.adoc[SELinux (en anglais)].
