= Installation sur RHEL/AlmaLinux/Rocky Linux/Oracle Linux

Ce chapitre décrit l'installation d'un serveur opsi à partir de paquets sur Red Hat Enterprise Linux (RHEL), AlmaLinux, Rocky Linux et Oracle Linux.

include::server:partial$package-based-start.adoc[]

== Préparatifs

Si vous utilisez Red Hat Enterprise Linux, vous devez vous enregistrer auprès du Red Hat Network pour accéder à tous les paquets nécessaires :

[source,console]
----
sudo subscription-manager register
sudo subscription-manager attach --auto
----

L'utilisation du dépôt Extra Packages for Enterprise Linux (EPEL) est également nécessaire pour satisfaire toutes les dépendances des paquets.

Sur AlmaLinux ou Rocky Linux, utilisez les commandes suivantes :

[source,console]
----
dnf config-manager --set-enabled crb
dnf install epel-release
----

Sur Oracle Linux, utilisez la commande suivante :

[source,console]
----
dnf install oracle-epel-release-el8
----
ou
[source,console]
----
dnf install oracle-epel-release-el9
----
ou
[source,console]
----
dnf install oracle-epel-release-el10
----

selon que vous utilisez Oracle Linux 8, 9 ou 10.

Si le système d'exploitation du serveur est Red Hat, utilisez les commandes suivantes :
[source,console]
----
dnf -y install https://dl.fedoraproject.org/pub/epel/epel-release-latest-8.noarch.rpm
----
ou
[source,console]
----
dnf -y install https://dl.fedoraproject.org/pub/epel/epel-release-latest-9.noarch.rpm
----
ou
[source,console]
----
dnf -y install https://dl.fedoraproject.org/pub/epel/epel-release-latest-10.noarch.rpm
----

selon que le système d'exploitation est Red Hat 8, 9 ou 10.



Installez Samba et MariaDB :

[source,console]
----
sudo yum install mariadb-server samba samba-client
----

Démarrez et configurez Samba et MariaDB :

[source,console]
----
sudo systemctl start smb.service
sudo systemctl start nmb.service
sudo systemctl start mariadb.service
sudo systemctl enable smb.service
sudo systemctl enable nmb.service
sudo systemctl enable mariadb.service
sudo mysql_secure_installation
----

NOTE: Si la machine doit également servir de serveur DHCP, le démon `dhcpd` doit être installé et configuré.

== Configuration des dépôts

Ajoutez le dépôt Grafana :

[source,console]
----
sudo cat <<EOF | sudo tee /etc/yum.repos.d/grafana.repo
[grafana]
name=grafana
baseurl=https://rpm.grafana.com
repo_gpgcheck=1
enabled=1
gpgcheck=1
exclude=*beta*
gpgkey=https://rpm.grafana.com/gpg.key
sslverify=1
sslcacert=/etc/pki/tls/certs/ca-bundle.crt
EOF
----

== Installation des paquets

Installez le paquet `opsi-server-full` :

[source,console]
----
sudo yum install opsi-server-full
----

Si un message vous demande de confirmer l'importation de la clé GnuPG du dépôt, saisissez simplement `y` et appuyez sur [Entrée] pour confirmer l'ajout de la clé :

[source,console]
[subs="attributes"]
----
Importing GPG key 0xD8361F81 "home:uibmz OBS Project <home:uibmz@build.opensuse.org>" from http://download.opensuse.org/repositories/home:/uibmz:/opsi:/4.3:/stable/distribution/repodata/repomd.xml.key
Is this ok [y/N]: y
----
