[[server-installation-deb]]
= Installation sur Debian/Ubuntu

Ce chapitre décrit l'installation d'un serveur OPSI à partir de paquets sur les systèmes Debian et Ubuntu.

include::server:partial$package-based-start.adoc[]

== Configuration des dépôts

Commencez par installer les paquets suivants :

[source,console]
----
sudo apt --yes install host apt-transport-https curl gpg
----

Assurez-vous que le répertoire `/usr/local/share/keyrings` existe :

[source,console]
----
sudo mkdir -p /usr/local/share/keyrings
----

Ajoutez le dépôt Grafana :

[source,console]
----
REPO_URL=https://apt.grafana.com
REPO_KEY=/usr/local/share/keyrings/grafana.gpg
curl -fsSL ${REPO_URL}/gpg.key | gpg --dearmor | sudo tee ${REPO_KEY} > /dev/null
echo "deb [signed-by=${REPO_KEY}] ${REPO_URL} stable main" | sudo tee /etc/apt/sources.list.d/grafana.list
----

Ajoutez le dépôt OPSI correspondant à votre distribution :

*Debian 13, _Trixie_ :*
[source,console]
[subs="attributes"]
----
REPO_URL=https://download.opensuse.org/repositories/home:/uibmz:/opsi:/4.3:/{release}/Debian_13
REPO_KEY=/usr/local/share/keyrings/opsi-obs.gpg
cat << __EOF__ | sudo tee /etc/apt/sources.list.d/opsi.sources
Types: deb
URIs: $REPO_URL
Suites: /
Signed-By: /usr/local/share/keyrings/opsi-obs.gpg
__EOF__
curl -fsSL ${REPO_URL}/Release.key | gpg --dearmor | sudo tee ${REPO_KEY} > /dev/null
----

Pour vérifier que l'importation de la clé GnuPG a réussi, vous pouvez exécuter la commande suivante :

[source,console]
----
gpg --show-keys /usr/local/share/keyrings/opsi-obs.gpg 2>/dev/null
----

La sortie de la commande devrait contenir des lignes semblables aux suivantes :

[source,console]
----
pub   rsa2048 2017-09-30 [SC] [expires: 2025-11-19]
      2E98F7B5A5B2C8FE7F609705D1F933E6D8361F81
uid           home:uibmz:opsi OBS Project <home:uibmz:opsi@build.opensuse.org>
----

== Installation des paquets

Installez le paquet `opsi-server-full` :

[source,console]
----
sudo apt update
sudo apt --yes install opsi-server-full
----

NOTE: Sur Debian 13, vous pouvez télécharger et exécuter le script `opsi-secure` en tant que `root` pour appliquer des paramètres de sécurité :

[source,console]
----
curl -fsSL https://tools.43.opsi.org/experimental/opsi-secure -o /tmp/opsi-secure && opsi-python /tmp/opsi-secure harden
----

Le script est actuellement en phase de test. Les paramètres qu'il applique peuvent également être appliqués sur tous les autres systèmes.
