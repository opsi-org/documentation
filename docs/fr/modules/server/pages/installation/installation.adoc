[[server-installation]]
= Installation et configuration

Ce chapitre présente les différentes possibilités d'installation d'un serveur OPSI. Avant de commencer l'installation, veuillez prendre connaissance des exigences matérielles suivantes pour le serveur.

[[server-installation-hardware-requirements]]
== Exigences matérielles

Vous pouvez exécuter un serveur OPSI directement sur une machine physique, dans une machine virtuelle ou dans un conteneur Docker. Les exigences matérielles peuvent varier considérablement selon la taille de votre environnement. Pour un fonctionnement efficace et fluide, les caractéristiques minimales suivantes doivent être respectées :

* Un système x86-64 ou ARM64
* 2{nbsp}Go de mémoire vive
* 2 cœurs de processeur

Un serveur de dépôt OPSI fonctionne principalement comme un serveur de fichiers, qui met des fichiers à disposition des clients. Un stockage de masse performant et une connexion réseau robuste sont donc essentiels.

La capacité de stockage nécessaire dépend principalement du nombre de paquets OPSI que vous souhaitez installer. Pour les systèmes de production, il est recommandé de prévoir au moins 60{nbsp}Go d'espace de stockage dans le répertoire `/var/lib/opsi`, avec une possibilité d'extension.

Selon la configuration et les activités quotidiennes, un nombre variable de clients OPSI peut accéder à un serveur OPSI. Dans les environnements de grande taille, où de nombreux clients se connectent simultanément, les besoins en mémoire vive et en puissance de calcul peuvent augmenter considérablement.

TIP: Le service central OPSI `opsiconfd` nécessite généralement environ 250{nbsp}Mo de mémoire vive par processus de travail. Il est conseillé de prévoir un processus de travail pour 20 connexions simultanées. En outre, le nombre de cœurs de processeur devrait correspondre approximativement à la moitié du nombre de processus de travail. Dans une configuration standard, vous devez également tenir compte des ressources supplémentaires nécessaires à Samba, MySQL et Redis.
