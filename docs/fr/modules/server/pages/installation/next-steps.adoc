[[server-installation-next-steps]]
= Étapes suivantes

Quel rôle votre nouveau serveur OPSI va-t-il jouer : serveur de configuration ou serveur de dépôt ? Les prochaines étapes d'installation et de configuration du serveur dépendent de ce choix.

== Serveur de configuration OPSI

* Si vous prévoyez d'utiliser des xref:opsi-docs-en:opsi-modules:modules.adoc[extensions OPSI payantes (en anglais)], c'est le moment d'xref:opsi-docs-en:opsi-modules:modules.adoc[importer vos fichiers de licence (en anglais)].
* Configurez le serveur et ses composants comme décrit dans le chapitre xref:opsi-docs-en:server:components/components.adoc[Outils et paramètres (en anglais)].
* Installez des logiciels supplémentaires, comme décrit dans la section xref:opsi-docs-en:server:components/commandline.adoc#server-components-opsi-package-updater-install-default-products[Installation des produits standard (en anglais)].
* Lancez l'xref:opsi-docs-en:gui:configed.adoc[interface de gestion *opsi-configed* (en anglais)].
* Définissez un xref:opsi-docs-en:server:components/backup.adoc[plan de sauvegarde (en anglais)] pour le serveur OPSI.

== Serveur de dépôt OPSI

Si le serveur est destiné à servir de serveur de dépôt OPSI, il est indispensable de l'enregistrer auprès du serveur de configuration OPSI. Pour cela, exécutez la commande suivante sur le serveur de dépôt OPSI :

[source,console]
----
opsiconfd setup --register-depot
----

NOTE: Si vous exécutez le serveur de dépôt OPSI dans un conteneur Docker, cette étape n'est pas nécessaire. Dans ce cas, les variables d'environnement contrôlent automatiquement ce comportement.
