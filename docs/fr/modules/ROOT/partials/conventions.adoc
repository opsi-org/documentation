== Conventions et notations

Dans ce manuel, nous utilisons les conventions suivantes pour la typographie et la mise en évidence :

* Les noms de fichiers et de répertoires sont présentés dans une `police proportionnelle`.
* Les commandes longues et les listings sont placés dans des blocs séparés. Vous pouvez facilement les reprendre par copier-coller :

[source,console]
----
this is a command
----

* Le code `opsi-script` est présenté comme suit :

[source,console]
----
Message "Installing "+ $ProductId$ +" ..."
----

* Les éléments entre `<chevrons>` sont des paramètres fictifs que vous devez remplacer par leurs valeurs réelles. Par exemple, le partage de fichiers contenant les paquets OPSI est désigné par `<opsi-depot-share>`. Sur un serveur réel, il se trouve généralement dans `/var/lib/opsi/depot`. Le paquet logiciel `<opsi-depot-share>/ooffice` se trouverait donc dans `/var/lib/opsi/depot/ooffice`.
* Les entrées de menu et les libellés des boutons sont présentés en _italique_.
* Les touches et les combinaisons de touches sont entourées de crochets, par exemple [C], [Ctrl]{plus}[C], etc.
