[[opsi-setup-detector-create-winget]]
=== Create a Opsi winget package

The following section describes how to create a winget based opsi product. +
`winget` is a Windows command line command with which you can install software directly from the Internet onto your computer. +
As a rule, winget must first be installed on the computer. +
To create a winget-based package, click on the _Create an opsi winget package_ button on the start page (<<osd_page_start>>). You will then see the following message:

.The *opsi-setup-detector* winget message.
image::opsi-modules:osd_installer_info_winget_en.png["The *opsi-setup-detector* winget message.", pdfwidth=80%, width=800]

After you have confirmed the message, you will see the following screen:

.The *opsi-setup-detector* winget input mask.
image::opsi-modules:osd_page_winget_en.png["The *opsi-setup-detector* winget input mask.", pdfwidth=80%, width=800]

Enter the `wingetId` and the `wingetSource` here. +
In the fields 'Command to install' and 'Command to uninstall' you can see which command is used to (un)install the software. +
The 'Next step' button then takes you to 'Product configuration 1', which you use in the same way as for the other tasks. +
 +
Typical `wingetSource` are `winget` and `msstore`. +
Tools for determining `wingetId` and `wingetSource` can be found here: +
`Unigetui` is a tool to be installed locally with which you can search for packages available on the net from various sources. If packages are found, you can obtain extensive information about the package via the context menu / package details. (Do not forget to scroll down). 
You may also find a link here where the original installer can be downloaded. + 
See: link:https://www.marticliment.com/unigetui/[unigetui] +
`winget.run` is a website with which the `wingetId` of packages from the source `winget` can be determined (i.e. not packages from the MS Store). +
See: link:https://winget.run/[winget.run] +
Further pages with detailed information on the `winget` command can be found at link:https://learn.microsoft.com/en-us/windows/package-manager/winget/[learn.microsoft] +
and at link:https://en.wikipedia.org/wiki/Windows_Package_Manager[wikipedia]
