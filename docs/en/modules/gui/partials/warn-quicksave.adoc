NOTE: The former _Quick Save_  feature has been removed. 
Configuration changes (attributes, parameters, product properties, and action requests) are now collected locally in the browser first. 
An _Unsaved Changes_ indicator appears in the toolbar showing how many changes are pending. 
You can review, selectively discard, or save all pending changes at once using the save/discard buttons or the _Unsaved Changes_ modal dialog. 
Changes are only written to the server when you explicitly click _Save_.
