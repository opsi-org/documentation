[[opsi-cli-installation]]
= OPSI-CLI Installation

`opsi-cli` is part of the `opsi-utils` package and is therefore installed automatically on OPSI servers. Since all communication takes place exclusively via the OPSI web service, `opsi-cli` is also available as an opsi package for Linux, Windows, and macOS clients. Hence, it can also be used outside the OPSI server. Installation packages for the respective operating systems can be found in the OPSI Tools repository at https://tools.43.opsi.org/stable.

When using `opsi-cli` outside of an OPSI server, you need to provide credentials for the OPSI web service. This can be done either directly in the command line with `--service`, `--username`, and `--password`, or by saving the credentials locally on the client (use `opsi-cli config service add --help` for guidance, see user guide xref:opsicli/userguide.adoc#opsi-cli-serviceoptions[Usage > Service Options]).

The `opsi-cli` executable is immediately executable and portable. If you want to include the binary in the path on an OPSI client, you can use `opsi-cli` itself for that (see `opsi-cli self --help`).

We recommend enabling auto-completion as your first command:

[source,console]
----
opsi-cli self setup-shell-completion
----
