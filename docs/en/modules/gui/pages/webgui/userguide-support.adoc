= Support

The _Support_ page in OPSI-WebGUI gives quick access to help resources and release notes.

You can open it from the left navigation bar: _Support_.

.OPSI-WebGUI: Support page
image::gui:webgui/opsi-webgui-support.png["OPSI-WebGUI: Support page"]

The page contains three link cards:

* *Professional support*: Opens the OPSI support page in your current language.
* *Community forum*: Opens `https://forum.opsi.org`.
* *Documentation*: Opens `https://docs.opsi.org`.

Below these cards, the _What's New_ section shows recent release notes.
If no changelog entries are available, the page shows a corresponding info message.
