[[opsi-manual-opsiwebgui-userguide]]
= User Guide

This guide covers working with the OPSI-WebGUI: logging in, the interface, and managing servers, clients, products, and groups.

[[opsi-manual-opsiwebgui-user-requirements]]
== Prerequisites

To use the OPSI-WebGUI you need:

* An up-to-date browser (Chrome/Chromium, Firefox, Safari, or Edge) with JavaScript enabled. If you use an add-on such as NoScript, allow the OPSI-WebGUI page.
* Network access to the OPSI config server (`opsiconfd`, port 4447). An internet connection is not required.
* A user account in the `opsiadmin` group (see xref:server:components/authorization.adoc[Authorizations]).

[[opsi-manual-opsiwebgui-login]]
== Getting Started

Open `\https://<opsi-server>:4447/addons/webgui/app` in your browser and log in.
The login page, authentication methods, SAML single sign-on, and what happens after login are described in xref:gui:webgui/userguide-login.adoc[Login and Routing].

The following chapters are ordered like a typical working session: first the login and the interface, then the pages in the same order as the OPSI-WebGUI's navigation bar.
