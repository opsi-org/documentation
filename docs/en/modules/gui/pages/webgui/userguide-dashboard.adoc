= Dashboard

The Dashboard gives a quick overview of your OPSI environment: server status, health, user permissions, and statistics.
Most cards are clickable and take you to the corresponding detail page.

.OPSI-WebGUI: Dashboard
image::gui:webgui/opsi-webgui-dashboard.png["OPSI-WebGUI: Dashboard"]

[[opsi-manual-opsiwebgui-dashboard-cards-row1]]
== Server, Health, and User

* *Config Server*: Shows the name of your OPSI config server. Informational only.
* *Health Check*: Summarizes the server's health check with error, warning, and OK counts as colored badges. Clicking the card opens _Admin > Diagnostics > Health Check_.
* *Current User*: Shows your username and your feature permissions as badges: _Read Only_, _Server Write_, _Depot Access_, _Client Create_, _Host Groups_, _Product Groups_, and _Terminal_. Restricted features are marked accordingly.

[[opsi-manual-opsiwebgui-dashboard-cards-row2]]
== System Information

The System Info card shows technical details of the config server; clicking it opens _Admin > Diagnostics > System Info_:

* `opsiconfd` version and Python version
* Operating system and hostname
* CPU (number of cores and model) and load average
* Memory (total and current usage)
* Whether the server runs inside Docker

[[opsi-manual-opsiwebgui-dashboard-cards-row3]]
== Statistics

* *Total servers*: Number of OPSI servers (config and depot servers). Clicking opens the Servers page.
* *Total clients*: Number of OPSI clients, with active/inactive counts and a breakdown by operating system (Windows, Linux, macOS). A tooltip shows the client count per depot. Clicking opens the Clients page.
* *Total products*: Number of products, split into localboot and netboot products. A tooltip shows the product count per depot. Clicking opens the Products page.
* *Modules*: Number of enabled OPSI modules. Clicking opens _Admin > Diagnostics > Modules_.

[[opsi-manual-opsiwebgui-dashboard-cards-failed-clients]]
== Failed Clients

If the health check reports clients with failed product actions, an additional card lists these clients together with the failed products as badges.
Use it to spot installation problems without opening the Clients page.
